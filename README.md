## About This Website

這個網站使用 **Hugo** 架設。

Hugo 是一套 Static Site Generator（靜態網站產生器），主要負責網站內容管理、頁面產生與整體網站建置。

本網站以 Hugo 作為網站架構工具，並透過 HTML、CSS 與 JavaScript 進行版面與互動設計，再使用 GitHub Actions 自動建置並部署至 GitHub Pages。

## Technologies Used

- **HTML** — 建立網站內容與頁面結構
- **CSS** — 負責排版、字體、色彩與視覺設計
- **JavaScript** — 處理簡單的互動效果
- **Markdown** — 撰寫與管理部分網站內容
- **Hugo** — 靜態網站產生與內容管理
- **GitHub** — 儲存與管理網站原始碼
- **GitHub Actions** — 自動建置與部署 Hugo 網站
- **GitHub Pages** — 公開網站並提供線上瀏覽
